# LiteViewer (DevViewer)

超轻量级开发者查看器：**看代码、看 Git 分支历史图谱、看/编辑 Markdown**。

- **体积**：单文件绿色版仅 **4.2MB**（相比 VS Code 1GB+ 节省 99.6% 空间）。
- **内存占用**：仅 ~35MB 左右，秒开无延迟。
- **技术栈**：Tauri 2.0 (Rust) + React 19 + Zustand + Tailwind CSS。

---

## 核心功能

### 1. Markdown 浏览与实时编辑
- **预览模式 (Preview)**：GitHub 风格排版，支持标题、表格、代码高亮、任务清单。
- **源码编辑模式 (Raw/Edit)**：快速查看原始 Markdown 文本，直接编辑并支持 `Ctrl+S` 保存。
- **双栏模式 (Split)**：左侧编辑、右侧实时渲染。

### 2. Git 分支历史图谱 (Git Graph)
- **拓扑分支图**：连接线与提交节点，清晰查看合并与提交演进。
- **提交详情**：作者信息、相对时间 (`1 hour ago`)、多行 Commit 信息、改动统计 (`+增 / -删`)。
- **分支/标签徽标**：本地分支 (`main`)、远程分支 (`origin/main`) 分色胶囊徽标。
- **差异对比 (Diff)**：单栏差异高亮行查看。
- **工作区未提交改动**：直观展示暂存与未暂存改动。

### 3. 轻量代码与文件浏览
- 极速文件树搜索与过滤。
- Prism 语法高亮（Rust, TypeScript, JavaScript, Python, JSON, CSS, HTML, TOML 等）。
- 一键复制代码、行号查看。

---

## 关联 .md 文件说明

可以将 Windows 系统的 `.md` 文件默认打开方式关联到此可执行文件：
1. 右键任意 `.md` 文件 -> **打开方式** -> **选择其他应用**。
2. 浏览并选中 `LiteViewer.exe`。
3. 勾选 **始终使用此应用打开 .md 文件** 即可。
